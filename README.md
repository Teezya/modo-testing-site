# МОДО — система тестирования

Минимальный проект: регистрация ученика, прохождение теста, итоговый балл и закрытая админ-панель.

## Требования
- Node.js 20+
- Аккаунт MongoDB Atlas и созданный кластер (в проекте настроено подключение к вашему кластеру)

## Запуск
1. Установите Node.js 20+ и в корне проекта выполните `npm run install:all`.
2. В MongoDB Atlas создайте Database User и добавьте свой текущий IP в **Network Access**.
3. В Atlas нажмите **Connect → Drivers → Node.js**. Для этого проекта уже подготовлена строка подключения к вашему кластеру в `server/.env.example`.
4. Скопируйте `server/.env.example` в `server/.env`. В строке `MONGODB_URI` замените `<DB_PASSWORD>` на новый пароль Database User. Если пароль содержит специальные символы (`@`, `#`, `/`, `:` и т. п.), URL-кодируйте их.
5. В `server/.env` задайте собственные длинные случайные значения для `JWT_SECRET` и `ADMIN_PASSWORD`. `ADMIN_LOGIN` можно оставить `admin` или изменить.
6. Не публикуйте `server/.env` и не отправляйте connection string с паролем другим людям.
7. Запустите `npm run dev`.
8. Откройте `http://localhost:5173`. Админ-панель: `http://localhost:5173/admin`.

Для первого входа в админ-панель используйте значения `ADMIN_LOGIN` и `ADMIN_PASSWORD` из `server/.env`.

## Как устроено
- Сервер хранит учеников, ответы и итоговые результаты в MongoDB.
- Правильные ответы находятся только на сервере.
- Ученик получает персональный токен; при обновлении страницы он продолжает текущую попытку.
- Повторная регистрация с тем же ФИО не блокируется автоматически: у разных учеников могут совпадать ФИО. Если нужно строго ограничить повторные попытки, потребуется отдельное правило идентификации.
- Это локальный проект. Для публикации в интернете нужно разместить сервер и клиент на хостинге, а MongoDB — в доступной облачной базе.

## Структура
- `client/` — React + TypeScript + Vite
- `server/` — Express + MongoDB (Mongoose)

## MongoDB Atlas
Инструкция: https://www.mongodb.com/docs/atlas/driver-connection/
Для подключения нужны три вещи: Atlas connection string, Database User и IP в Network Access. Для локальной разработки можно временно разрешить `0.0.0.0/0`, но это открывает сетевой доступ с любых IP; используйте сложный пароль Database User и ограничьте IP при публикации.

## Отчёты по классам

В админ-панели добавлен раздел «Отчёт по классу». Выберите конкретную школу и класс, затем скачайте единый DOCX или отправьте его учителю. В документ входят общая статистика, сводная таблица учеников, статистика по вопросам и подробный разбор ответов каждого завершившего тест ученика.

Для отправки почты добавьте в Render → modo-api → Environment переменные `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` и `TEACHER_EMAIL`. Для Gmail используйте пароль приложения, а не пароль от аккаунта. Секреты не добавляйте в GitHub.

После обновления проекта установите новые серверные зависимости командой `npm install` в папке `server` (Render выполнит её автоматически при следующем Deploy).
